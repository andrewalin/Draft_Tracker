Auction Value

Rankings tell you order, but auction value shows distance. The sparkline graphs the remaining auction values at each position so cliffs, flat spots, and replacement-level drops are easier to see while you draft.

Color Cues

  • Green rows are your drafted players.
  • Red rows are players drafted by competitors.
  • Blue rows and blue sparkline dots are handcuffs for players you drafted.

Notes

Filters apply before keyboard shortcuts, so Enter acts on the first player currently shown. Draft state is saved in this browser.
